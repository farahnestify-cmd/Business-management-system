# Nestify Desk — نظام إدارة الأعمال

نظام إدارة أعمال كامل (مبيعات، مخزون، جهات اتصال، مالية، رواتب) بنفس شكل وطريقة عمل النسخة الأصلية.

| الطبقة | التقنية |
|---|---|
| الواجهة (Frontend) | HTML + CSS + JavaScript عادي (بدون build، بدون npm) — `public/assets/` و `resources/views/app.blade.php` |
| الخلفية (Backend) | Laravel 12 (PHP 8.2+) — `app/Http/Controllers/Api/` |
| قاعدة البيانات | MySQL / MariaDB — الجداول في `database/migrations/` |

## الأقسام

- **Today**: الأرقام الرئيسية وقائمة "Needs your attention" (فواتير متأخرة، عروض قديمة، مخزون منخفض، طلبيات متأخرة، رواتب مستحقة).
- **Sales**: عروض الأسعار ← اتفاقية ← فاتورة ← تسليم. أرقام مرجعية بصيغة `YYMM + منطقة (W/F) + نوع (D/P) + عداد`، دفعات (كاش / تحويل بنكي / شيك)، وطباعة عرض سعر، اتفاقية، فاتورة، سند تسليم، وإيصال.
- **Inventory**: منتجات جاهزة، قواعد (Bases) وأغطية (Covers)، الكميات المحجوزة والقادمة، طلبيات الشراء (الاستلام يضيف المخزون ويسجل التكلفة تلقائياً)، والموردين.
- **Contacts**: موزعين، شركاء، مستخدمين نهائيين، مع كشف حساب لكل واحد.
- **Money**: الربح والخسارة الشهري، المصاريف، ودفتر الصندوق.
- **Team**: الرواتب — **للمالك فقط**. حسابات الموظفين (Staff) ما بتوصلها أي بيانات رواتب من السيرفر.
- **Company settings**: بيانات الشركة، نصوص المستندات، الحدود والتنبيهات، إدارة الحسابات، وتغيير كلمة المرور.

## الرفع على الاستضافة المشتركة (Hostinger / cPanel / hPanel)

ما بتحتاج SSH ولا Composer على السيرفر.

### 1) جهّز ملف الرفع (فيه مجلد `vendor` جاهز)

- من GitHub: تبويب **Actions** ← آخر تشغيل ناجح لـ *Tests and upload package* ← تحت **Artifacts** نزّل `nestify-desk`.
- أو على جهازك (إذا عندك PHP و Composer): `./build-deploy.sh` بطلعلك `nestify-desk.zip`.

### 2) جهّز الاستضافة

1. من لوحة التحكم اختار **PHP 8.2 أو أحدث**.
2. من **MySQL Databases** اعمل قاعدة بيانات جديدة ومستخدم، وأعطِ المستخدم كل الصلاحيات على القاعدة. احتفظ بالاسم والمستخدم وكلمة المرور.

### 3) ارفع الملفات

ارفع **محتويات** مجلد `nestify-desk` (مش المجلد نفسه) إلى `public_html` عن طريق File Manager (ارفع الـ zip وفك ضغطه هناك).
ملف `.htaccess` الموجود بالمجلد الرئيسي بحوّل كل الطلبات لمجلد `public/`، فملفات مثل `.env` والكود ما بتنفتح من المتصفح.

> إذا الاستضافة بتسمحلك تغيّر Document Root للدومين، الأفضل ترفع المشروع لمجلد خارج `public_html` وتوجّه الدومين على مجلد `public` مباشرة.

تأكد إن المجلدات `storage/` و `bootstrap/cache/` قابلة للكتابة (صلاحيات 755 أو 775).

### 4) شغّل المثبّت

افتح موقعك بالمتصفح، رح يحوّلك تلقائياً على `/install`:

1. اكتب بيانات قاعدة البيانات من الخطوة 2 (الـ Host غالباً `localhost`).
2. اكتب اسمك وإيميلك وكلمة مرور حساب المالك.
3. اضغط **Install**. المثبّت بيكتب ملف `.env`، بيعمل مفتاح التشفير، بينشئ كل الجداول، وبيسكّر حاله بعد ما يخلص.

بعدها سجّل دخول، ومن **Company settings** عبّي بيانات الشركة وضيف حسابات الموظفين.

## التشغيل على جهازك (للتطوير)

```bash
composer install
cp .env.example .env          # عدّل بيانات MySQL وخلي APP_INSTALLED=true
php artisan key:generate
php artisan migrate --seed    # بيعمل حساب مالك من OWNER_EMAIL / OWNER_PASSWORD
php artisan db:seed --class=DemoSeeder   # اختياري: بيانات تجريبية
php artisan serve
```

الاختبارات: `php artisan test`

## بنية المشروع

```
app/Http/Controllers/Api/   API بصيغة JSON (المبيعات، الطلبيات، المصاريف، الرواتب، الإعدادات، الحسابات)
app/Models/                 الجداول وتحويلها لنفس الشكل اللي بتستخدمه الواجهة
app/Support/Installer.php   مثبّت الويب للاستضافة المشتركة
database/migrations/        جداول MySQL
public/assets/css/app.css   التصميم
public/assets/js/app.js     منطق الواجهة (التقارير والحسابات بتصير بالمتصفح زي الأصل)
resources/views/            الصفحة الرئيسية، تسجيل الدخول، والمثبّت
```

العمليات اللي بتغيّر أكثر من شي مع بعض (تسليم بيخصم من المخزون، استلام طلبية بيضيف مخزون ومصروف، رقم مرجعي جديد) بتصير على السيرفر داخل Database transaction، فما بصير تضارب لو أكثر من شخص شغال بنفس الوقت. الصفحة بتحدّث البيانات تلقائياً كل 30 ثانية.
