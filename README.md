# Nestify Desk — نظام إدارة الأعمال

نظام إدارة أعمال كامل (مبيعات، مخزون، جهات اتصال، مالية، رواتب) بنفس شكل وطريقة عمل النسخة الأصلية.

| الطبقة | التقنية |
|---|---|
| الواجهة (Frontend) | HTML + CSS + JavaScript عادي (بدون build، بدون npm) — `public/assets/` و `resources/views/app.blade.php` |
| الخلفية (Backend) | Laravel 12 (PHP 8.2+) — `app/Http/Controllers/Api/` |
| قاعدة البيانات | MySQL / MariaDB — الجداول في `database/migrations/` |

## الأقسام

- **Today**: الأرقام الرئيسية وقائمة "Needs your attention" (فواتير متأخرة، عروض قديمة، مخزون منخفض، طلبيات متأخرة، رواتب مستحقة).
- **Sales**: عروض الأسعار ← اتفاقية ← فاتورة ← تسليم. أرقام مرجعية بصيغة `YYMM + منطقة (W/F) + نوع (D/P) + عداد`، دفعات (كاش / تحويل بنكي / شيك)، وطباعة عرض سعر، اتفاقية، فاتورة، سند تسليم، وإيصال.
- **Inventory**: منتجات جاهزة، قواعد (Bases) وأغطية (Covers)، الكميات المحجوزة والقادمة، طلبيات الشراء (الاستلام يضيف المخزون ويسجل التكلفة تلقائياً)، والموردين.
- **مراجعة العرض**: زر **Revise for the client** بيعمل نسخة جديدة من العرض (‎2611WD04-V2). النسخ القديمة بتضل، ولما وحدة تصير Agreement الباقي بيتلغى.
- **مجموعات جاهزة**: **Save as a set** بيحفظ أسطر العرض، و**Start from a set…** بيضيفها لأي عرض بكمية 0 (الأسطر اللي بتضل 0 بتنطبع كخيارات). القائمة بـ Inventory ← Offer sets.
- **المسودة**: العرض بينحفظ بالمتصفح وانتي بتكتبي، وإذا تسكّر قبل الحفظ بترجعيله.
- **الخدمات والأجور** (Inventory ← Services): تركيب، برمجة، زيارات… بسعر للساعة أو الزيارة أو النقطة. بتنضاف على عروض الأسعار زي المنتجات، بس ما بتأثر على المخزون ولا إلها تكلفة.
- **أنواع الكفرات (Q, S…)** (Inventory ← Cover types): لكل نوع قيمة بتنضاف على سعر الـ base للمستخدم النهائي وللموزع. بالعرض بتختاري الـ base ونوع الكفر بس، والعميل بيشوف اسم الـ base وسعره بدون اللون والنوع. لكل base لحد 4 صور لكل نوع بتنطبع جنب بعض بخانة الصورة. بعد موافقة العميل، زر **Choose cover colours** بالصفقة بيقسم كل سطر على الألوان وكمياتها، والكفرات بتنحجز وبتنقص من المخزن عند التسليم.
- **بطاقة الصنف**: الضغط على أي صنف بالمخزن بيفتح بطاقة فيها: لأي اتفاقية أو فاتورة محجوز وكم، الطلبيات الجاية، وتاريخ كل حركة (لمين تسلّم، إيمتى، وكم، وشو انستلم من الموردين).
- **التسليم الجزئي**: زر Deliver بيسلّم الموجود بالمخزون بس، والباقي بيضل بقائمة **Inventory ← To deliver** لحد ما توصل البضاعة. الصفقة بتصير Delivered لما يتسلّم كل إشي.
- **بعد التسليم** (من الصفقة بعد الفاتورة): **Return an item** لما يرجع جهاز (إما بيتبدّل وبينسلّم مرة ثانية، أو بينشال من الفاتورة)، و**Deliver an extra item** لجهاز مش موجود بالعرض (بينضاف كسطر جديد وبينسلّم من المخزن، وبسعر 0 إذا مجاني). كل حركة طلوع ورجوع بتنسجل بـ **Delivery log** بالصفقة وعلى سند التسليم وببطاقة الصنف.
- **Contacts**: موزعين، شركاء، مستخدمين نهائيين، مع كشف حساب لكل واحد.
- **فئات الأسعار** (Contacts ← Price tiers): مثل Dealer Gold أو Partner Silver. كل فئة بتحدد من أي عمود أسعار بينسعّر العميل (أسعار الموزع أو المستخدم النهائي)، وخصم الفئة، وهدف المبيعات السنوي. خصم العميل الإضافي بينضاف فوق خصم الفئة. الخصم بيتعبّى لحاله بخانة **Discount on the total (%)** بالعرض (وبتقدري تغيّريه)، والأسعار بتطلع بسعر الكتالوج، وتحت **Total Price** بينطبع سطر **Total price discount X %** مع المبلغ بعد الخصم. الخدمات ما عليها خصم.
- **العملات** (Company settings ← Currencies): الحسابات كلها بالدولار. بتضيفي عملة (مثلاً ILS) وسعر صرفها، وبالعرض بتختاري **Quote in**. كل صفقة بتحفظ سعر الصرف اللي انكتبت فيه، والتقارير والصندوق بيحوّلوا للدولار. الصفقة اللي عليها دفعات بتضل بنفس عملتها.
- **زر التراجع**: بعد تسجيل دفعة، تغيير مرحلة، تسليم، حذف، أو دفع راتب، بيطلع زر **Undo** لمدة 10 دقائق.
- **Money**: الربح والخسارة الشهري، المصاريف، ودفتر الصندوق.
- **Reports** (للمالك): تقرير شهري بتختاري شهره: الكاش اللي دخل واللي طلع والصافي، عروض الأسعار اللي انوافق عليها ومجموعها، المبالغ اللي لسا عند العملاء، وحركة المخزون (استلام، رجوع، تسليم) جنب الموجود اليوم. وبينزل كملف Excel.
- **Team**: الرواتب — **للمالك فقط**.
- **الصلاحيات** (من Company settings ← Accounts):
  - **Owner**: كل إشي.
  - **Admin**: المبيعات والعملاء والمخزون، وتعديل الكتالوج والإعدادات. بدون Money و Team وطلبيات الشراء والموردين، وبدون أسعار التكلفة والأرباح.
  - **Sales**: عروض الأسعار والصفقات والعملاء وكميات المخزون بس.
  - أسعار التكلفة والمصاريف والرواتب ما بتطلع من السيرفر أصلاً لغير المالك، وأي عملية ممنوعة السيرفر بيرفضها.
- **Company settings**: بيانات الشركة، نصوص المستندات، الحدود والتنبيهات، إدارة الحسابات، وتغيير كلمة المرور.
- **Your data** (للمالك): تنزيل نسخة احتياطية كاملة بملف واحد، الاسترجاع منها، وتنزيل كل البيانات كملف Excel. **Recently deleted**: أي إشي بينحذف بيروح هون، وبيرجع بضغطة.

- **النسخ الاحتياطي** (Company settings ← Your data): زر **Back up now** بيحفظ نسخة كاملة على السيرفر وبينزّلها. **Automatic backup** (كل أسبوعين افتراضياً) بيعمل نسخة لحاله أول ما المالك يفتح النظام بعد ما تخلص المدة، وبتنزل لحالها على الجهاز. النسخ بتنحفظ بـ `storage/app/private/backups` (آخر 12 تلقائية و12 يدوية).

> **نقل بياناتك من جهازك للاستضافة:** من جهازك نزّل **Download a full backup**، وعلى الاستضافة بعد التثبيت اضغط **Restore from a backup** واختار الملف.

## الرفع على الاستضافة المشتركة (Hostinger / cPanel / hPanel)

ما بتحتاج SSH ولا Composer على السيرفر.

### 1) جهّز ملف الرفع (فيه مجلد `vendor` جاهز)

- من GitHub: تبويب **Actions** ← آخر تشغيل ناجح لـ *Tests and upload package* ← تحت **Artifacts** نزّل `nestify-desk`.
- أو على جهازك (إذا عندك PHP و Composer): `./build-deploy.sh` بطلعلك `nestify-desk.zip`.

### 2) جهّز الاستضافة

1. من لوحة التحكم اختار **PHP 8.2 أو أحدث**.
2. من **MySQL Databases** اعمل قاعدة بيانات جديدة ومستخدم، وأعطِ المستخدم كل الصلاحيات على القاعدة. احتفظ بالاسم والمستخدم وكلمة المرور.

### 3) ارفع الملفات

ارفع **محتويات** مجلد `nestify-desk` (مش المجلد نفسه) إلى `public_html` عن طريق File Manager (ارفع الـ zip وفك ضغطه هناك).
ملف `.htaccess` الموجود بالمجلد الرئيسي بحوّل كل الطلبات لمجلد `public/`، فملفات مثل `.env` والكود ما بتنفتح من المتصفح.

> إذا الاستضافة بتسمحلك تغيّر Document Root للدومين، الأفضل ترفع المشروع لمجلد خارج `public_html` وتوجّه الدومين على مجلد `public` مباشرة.

تأكد إن المجلدات `storage/` و `bootstrap/cache/` قابلة للكتابة (صلاحيات 755 أو 775).

### 4) شغّل المثبّت

افتح موقعك بالمتصفح، رح يحوّلك تلقائياً على `/install`:

1. اكتب بيانات قاعدة البيانات من الخطوة 2 (الـ Host غالباً `localhost`).
2. اكتب اسمك وإيميلك وكلمة مرور حساب المالك.
3. اضغط **Install**. المثبّت بيكتب ملف `.env`، بيعمل مفتاح التشفير، بينشئ كل الجداول، وبيسكّر حاله بعد ما يخلص.

بعدها سجّل دخول، ومن **Company settings** عبّي بيانات الشركة وضيف حسابات الموظفين.

## التشغيل على جهازك (للتطوير)

```bash
composer install
cp .env.example .env          # عدّل بيانات MySQL وخلي APP_INSTALLED=true
php artisan key:generate
php artisan migrate --seed    # بيعمل حساب مالك من OWNER_EMAIL / OWNER_PASSWORD
php artisan db:seed --class=DemoSeeder   # اختياري: بيانات تجريبية
php artisan serve
```

الاختبارات: `php artisan test`

بعد ما تسحب تحديث جديد (`git pull`) شغّل دايماً `php artisan migrate` عشان أي تعديل على الجداول ينطبق على قاعدة بياناتك. بياناتك ما بتنمسح.

## بنية المشروع

```
app/Http/Controllers/Api/   API بصيغة JSON (المبيعات، الطلبيات، المصاريف، الرواتب، الإعدادات، الحسابات)
app/Models/                 الجداول وتحويلها لنفس الشكل اللي بتستخدمه الواجهة
app/Support/Installer.php   مثبّت الويب للاستضافة المشتركة
database/migrations/        جداول MySQL
public/assets/css/app.css   التصميم
public/assets/js/app.js     منطق الواجهة (التقارير والحسابات بتصير بالمتصفح زي الأصل)
resources/views/            الصفحة الرئيسية، تسجيل الدخول، والمثبّت
```

العمليات اللي بتغيّر أكثر من شي مع بعض (تسليم بيخصم من المخزون، استلام طلبية بيضيف مخزون ومصروف، رقم مرجعي جديد) بتصير على السيرفر داخل Database transaction، فما بصير تضارب لو أكثر من شخص شغال بنفس الوقت. الصفحة بتحدّث البيانات تلقائياً كل 30 ثانية.
